# ClearPath retirement record

Retired on November 8, 2026 at the repository owner's request, after the November 7 Claude Impact Lab hackathon.

The hosted ClearPath demo is offline. The project has no active deployment or maintenance commitment. The remaining README describes the historical prototype and how to run it locally, not a currently supported service.

## Preserved

- Committed source, branch history, reviewed Irvine ADU data, citations, and source-conflict notes.
- Both frontend versions: the API-oriented app in `clearpath/` and the dashboard in `frontend/`.
- Fictional PDF/ZIP demo packets and their generators and regression tests.
- Private local recovery copies of Git history, deployment configuration, static exports, and database dumps. These operational backups and credentials are not published in this repository.

The final deployed dashboard was commit `e65d31aa99b7c5578c692147936327abfbc57552`. Archiving preserves other branches without merging unfinished work into `main`.

## Limits

Municipal sources were reviewed for the hackathon on November 7, 2026 and are not being refreshed. Filename matching does not validate a document's contents, completeness, or acceptance by a city. Navigator responses remain prototype behavior. Re-check every source and configure authentication before reusing or publishing the application.
